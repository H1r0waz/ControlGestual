Control con la mano

Cámara apagada

Destino de los gestos: escritorio.

Puño + lateral: mover. Abajo: minimizar. Arriba: maximizar/restaurar. Abrí para confirmar.

Con el perfil Ventanas, el puño mueve entre monitores, minimiza o maximiza. También podés usar las combinaciones de dedos de abajo. Abrí para confirmar. Verde: mano detectada. Ámbar: gesto capturado. Pulgar + anular admite diagonales claras.

F8 pausa la cámara y el micrófono desde cualquier aplicación. Escape pausa ambos controles cuando este panel está enfocado.

Contactos con el pulgar · siempre disponibles

Primero abrí la mano. Juntá la punta de un dedo con el pulgar durante medio segundo, desplazá manteniendo el contacto y separalos para confirmar. Mantené los otros dedos relajados y al menos dos extendidos.

  • Puño: conserva las acciones del perfil elegido. Se confirma abriendo la mano.
  • Pulgar + índice: ← → ↑ ↓ acomoda en la mitad correspondiente.
  • Pulgar + medio: ← anterior / → siguiente aplicación; ↑ maximizar/restaurar; ↓ minimizar.
  • Pulgar + anular: ↖ ↗ ↙ ↘ acomoda en el cuarto correspondiente.
  • Pulgar + meñique: ← aplicación anterior / → siguiente. Arriba y abajo quedan desactivados.

Se reconoce la cercanía de las puntas; la cámara no mide presión. Esperá a ver la ventana seleccionada antes de desplazar. Si tocás varios dedos a la vez o cambiás de dedo durante el recorrido, el contacto se cancela.

Personalizar acciones de los dedos

Estas asignaciones son independientes del perfil del puño. Elegí Desactivado para ignorar una combinación.

Perfiles y gestos personalizados del puño

Siempre: mano abierta, cerrar puño, desplazar y abrir para confirmar. Elegí Desactivado para ignorar una dirección.

Ajustar a tu mano

Menor porcentaje: menos movimiento. Mayor porcentaje: evita movimientos pequeños.

Detección predeterminada.

Primero capturá la mano abierta y después el puño. Durante la calibración no se ejecutan gestos.

Conversación con Jarvis

Encendé Qwen para conversar y pedir acciones con frases más libres. Las órdenes conocidas siguen disponibles con la IA apagada.

IA apagada.

Ejemplos: «¿Qué diferencia hay entre RAM y almacenamiento?» o «Dejá esta ventana ocupando toda la pantalla». Una acción interpretada por Qwen se muestra como propuesta y espera tu confirmación. No puede ejecutar comandos, abrir apps, leer archivos o consultar internet.

Las órdenes usan siempre el modo preciso: «Control Chrome», «Control Discord», «Control seleccionar Spotify». Elegí una app abierta; no se inicia si está cerrada. Para una consulta libre, encendé IA y micrófono y decí Control pregunta o pulsá Dictar consulta. Hablá cuando indique que está escuchando. Después de una frase vuelve solo a las órdenes.

La conversación conserva su ventana objetivo. Si hay varias ventanas de una app, primero te pide elegir. Para cambiar el objetivo, nombrá otra aplicación, elegí otra ventana en la lista o reiniciá la conversación.
